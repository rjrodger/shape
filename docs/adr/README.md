# Architecture decision records

Decisions about Shape's design that are expensive to revisit, with the reasoning
that produced them. An ADR records *why*, so a later reader can tell a
deliberate constraint from an accident.

These are not user documentation—for that, start at the
[docs index](../README.md). An ADR is only superseded by another ADR.

| - | -------- | ------ |

| [0002](0002-nof-replaces-one-and-some.md) | `Nof` replaces `One` and `Some` | Accepted |
| [0003](0003-rust-builders-keep-their-canonical-names.md) | Rust builders keep their canonical names | Accepted |
